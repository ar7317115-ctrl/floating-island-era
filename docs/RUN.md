# 本地运行《浮岛时代 V0.1》

## 环境

需要安装 Node.js 18 或更高版本。

## 启动

在项目根目录打开终端：

```bash
npm start
```

启动成功后打开：

```
http://localhost:3000
```

## 当前可玩内容

- 食物 / 淡水持续消耗
- 前五次钓鱼的新手保底
- 随机钓取资源
- 人物箱
- 未知箱
- 土方扩岛
- 住所 / 农田 / 储存棚
- 人物唯一实例
- 人口增加后粮水压力增大
- 新手保护根据掌握度逐步降低
- 弱怪事件雏形

## 技术说明

所有关键状态均保存在服务端内存中，客户端只发送操作意图。

V0.1 仍是原型：关闭服务端后状态会重置。后续版本再接数据库与账号系统。
