# 浮岛时代 Floating Island Era

> 一根鱼竿，从一座小岛，钓出一个文明。

《浮岛时代》是一款以 **生存 → 建设 → 人口 → 文明 → 探索 → 贸易 → 冲突 → 重建** 为核心循环的多人在线文明生存策略游戏。

## V0.1 目标

第一版只证明一件事：**核心循环好不好玩。**

玩家将能够：

- 从一座极小浮岛开始
- 处理真实的食物与淡水生存压力
- 通过钓鱼获得食物、木材、种子、土方、人物与未知箱子
- 使用土方扩建浮岛
- 建造基础生存设施
- 获得拥有职业与技能的人物
- 给人物分配工作
- 探索迷雾区域
- 遇到危险箱和怪物
- 体验新手保护逐渐减弱后的第一层世界压力

## 技术原则

- 客户端不可信
- 关键状态由服务器权威判定
- 世界隐藏信息不提前下发给客户端
- 游戏经济采用可追溯流水
- 人物、道具、交易均使用唯一实例 ID
- 后续 AI 文明、海盗、怪物生态独立于玩家运行

## 项目结构

- `client/` 游戏客户端
- `server/` 权威游戏服务器
- `shared/` 共享类型、规则、人物与资源数据
- `world-ai/` 世界 AI 与节奏导演
- `docs/` 设计与技术文档
