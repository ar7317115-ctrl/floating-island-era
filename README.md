# 浮岛时代 Floating Island Era

> 一根鱼竿，从一座小岛，钓出一个文明。

《浮岛时代》是一款以 **生存 → 建设 → 人口 → 文明 → 探索 → 贸易 → 冲突 → 重建** 为核心循环的多人在线文明生存策略游戏。

## 当前版本：V0.3 开发中

已实现的原型功能：
- 小浮岛、15×15 格子世界与迷雾
- 食物、淡水、木材、土方、种子
- 钓鱼、扩岛、简易住所、农田、储存棚
- 跨时代人物样本、职业技能与工作分配
- 怪物实体、攻击、守卫和人物死亡风险
- 新手保护阶段
- 服务端自动 JSON 存档
- 食物腐败与储存棚减损机制

## 启动方式（Windows）

1. 安装 Node.js 18 或更高版本。
2. 双击项目根目录的 `start-game.bat`。
3. 浏览器访问 `http://localhost:3000`。
4. 存档会自动保存在 `save-data/world-save.json`，该目录已加入 Git 忽略，不会被意外提交到仓库。

## 技术原则

- 客户端不可信；关键状态由服务器权威判定
- 世界隐藏信息不提前下发给客户端
- 后续正式联网版本必须加入账号认证、权限校验、限流、审计日志和数据库备份
- 当前 JSON 存档仅适合单机原型，不是正式多人线上存档方案
- 不在核心循环验证前加入正式充值

## 项目结构

- `client/` 游戏客户端
- `server/` 游戏服务器与规则
- `shared/` 人物与规则数据
- `world-ai/` 未来世界 AI 与节奏导演
- `docs/` 设计与技术文档

## 重要说明

当前项目是可继续迭代的原型，不代表已经完成线上多人游戏、安全审计或商业化部署。正式上线前必须进行自动化测试、并发与安全测试。
