# 浮岛时代

一款以悬浮岛屿、生存建造、钓鱼探索与文明进化为核心的策略游戏项目。

## 游戏方向

- 开局从简陋漂浮艇或小型浮岛起步，解决食物、水与基础物资等生存需求。
- 通过钓鱼探索获得物资、种子、木材、人物、土方与船舶零件。
- 建造和扩展岛屿，逐步发展到未来科技与反重力文明。
- 新手保护阶段免受玩家侵略、海盗与怪兽袭击，具体规则待实现。
- 中后期逐步开放联盟、交易、世界探索与竞争玩法。
- 以清晰的阶段目标和新内容支撑成长节奏。

## 当前状态

项目初始化阶段。本文件记录产品方向；仓库尚未包含可运行游戏。

## 开发顺序

1. 实现可运行的单人原型：资源、生存、钓鱼、建造与保存进度。
2. 增加科技树、探索事件与新手引导。
3. 根据原型测试反馈确定移动端或微信小程序的发布方案。
4. 再开发需要服务器的账号、交易与联盟功能。
