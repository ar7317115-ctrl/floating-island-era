# 核心游戏规则

## 1. 生存优先

文明建立之前必须先活下来。

核心生存资源：

- 淡水
- 食物
- 住所
- 后续：燃料、医疗、温度

食物与淡水会持续消耗。

### 生存状态

- 充足：正常工作
- 紧张：效率轻度下降
- 饥饿：效率显著下降
- 严重饥荒：疾病、逃亡、争抢
- 长期断粮：人物可能死亡

新手期存在隐藏保护，避免因纯随机导致死档。

## 2. 钓鱼是世界入口

钓鱼可以获得：

- 水
- 食物
- 木材
- 石材
- 种子
- 土方
- 工业资源
- 工具与零件
- 人物
- 未知箱
- 危险生物

## 3. 人物不是卡片投影

人物进入世界后是真实存在的角色，拥有：

- 年龄
- 健康
- 职业
- 技能
- 性格
- 偏好
- 关系
- 弱点
- 学习能力
- 唯一实例 ID

## 4. 世界是隐藏网格

底层使用坐标网格，但视觉上保持自然。

每个格子包含：

- 坐标
- 地形
- 高度
- 资源
- 所属
- 可见性
- 危险度
- 生态状态

## 5. 新手保护

保护并非永久存在。

阶段：

1. 绝对安全
2. 低风险
3. 弱怪出现
4. 远方威胁被观察到
5. 海盗侦察
6. 正式进入动态世界

推进依据包含玩家掌握度，而非只按注册天数。
